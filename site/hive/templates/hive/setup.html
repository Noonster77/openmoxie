LM Studio quick setup
  1. Run setup-lm-studio-model.bat.
  2. The script starts the LM Studio daemon and restarts the API listener on 0.0.0.0:1234 so Docker can connect.
  3. Copy the reported model identifier above and select LM Studio (local).

With LM Studio selected for chat and faster-whisper selected for speech, ordinary conversations stay local.

OpenRouter quick setup
  1. Create an OpenRouter API key.
  2. Select OpenRouter and paste the key above.
  3. Enter the exact OpenRouter model ID.
  4. Keep the base URL at https://openrouter.ai/api/v1.
