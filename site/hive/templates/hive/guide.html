Everyday help

Family guide

The useful things to know when setting up Moxie, starting an activity, and fixing common problems.

Open Control Center
1

Start OpenMoxie

Start Docker Desktop, run start-openmoxie.bat, and wait for MQTT and Moxie to show green in Control Center.

2

Start a conversation

Use Chat on Moxie's card, or say “Moxie, talk about something else.” Homework, Reasoning, Trivia, and Jokes are beside it.

3

Make Moxie personal

Open Family & voice to add the names Moxie may recognize, choose a nickname, and adjust speech pace and volume.

4

Review and control

Live room shows current activity. Conversation privacy lets a parent review, download, or delete locally stored history.

Using Vision and I Spy

When something is not working

Moxie says Offline

Keep Docker running, confirm Moxie and this computer are on the same home network, then restart Moxie's Wi-Fi connection.

Moxie hears the wrong words

Speak one short sentence, reduce nearby noise, and try a larger local Whisper model in Setup if the computer can handle it.

LM Studio does not answer

Run setup-lm-studio-model.bat again. It loads the model, starts the network listener, and verifies Docker access.

Vision has no picture

Keep Moxie awake, leave Puppet mode, check both router DNS overrides, and confirm the detector says Ready in Setup.

An activity seems stuck

Press Chat or Stop, wait a few seconds, then use Live room to see whether the robot confirmed the command.

Need to undo local records

Use Conversation privacy for transcripts. Setup contains database content reload, export, and advanced maintenance.
